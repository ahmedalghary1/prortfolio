# منشئ بورتفوليو باستخدام Django

تطبيق صغير يحول قالب `Portfolio---Bootstrap` الموجود في هذا المشروع إلى صفحات بورتفوليو ديناميكية. يسجل المستخدم حسابًا، ويدخل بياناته ومشاريعه في لوحة التحكم، ثم يحصل على رابط عام بالشكل `/p/<slug>/`.

## التشغيل محليًا

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

افتح `http://127.0.0.1:8000/`، أنشئ حسابًا، ثم افتح لوحة التحكم. يمكن إنشاء أكثر من بورتفوليو وتعديلها. الصور المرفوعة تخزن في `media/`.

- يتولد الرابط المختصر تلقائيًا من الاسم العربي أو الإنجليزي. إذا تكرر الاسم، يضاف رقم إلى الرابط. يبقى رابط الصفحة ثابتًا عند تعديل الاسم حتى لا تتعطل الروابط التي شاركتها.
- اكتب كل مهارة في سطر منفصل، أو افصل المهارات بفاصلة عربية أو إنجليزية. إذا تركت الحقل فارغًا، تستخدم مهارات القالب: HTML وCSS وBootstrap وJavaScript.
- إذا تركت جميع المشاريع فارغة، تضاف مشاريع القالب الثلاثة تلقائيًا ويمكن تعديلها لاحقًا.

## النشر

اضبط `DJANGO_SECRET_KEY` لقيمة عشوائية، و`DJANGO_DEBUG=0`، و`DJANGO_ALLOWED_HOSTS` لأسماء النطاقات، ثم نفّذ `python manage.py collectstatic`. يجب أن يخدم خادم الويب ملفات `staticfiles/` و`media/`، وأن تبقى قاعدة البيانات والملفات المرفوعة محفوظة بشكل دائم.
